# YARIS browser extensions

Release title: **extensions**
Suggested GitHub release tag: `extensions`

This release provides the YARIS idle screensaver for Chrome, Opera, and Firefox.
The attached `YARIS-extensions.zip` contains installable browser-specific
packages and setup instructions:

- `YARIS-Chrome-Opera.zip` — unpacked Chromium extension for Chrome and Opera.
- `YARIS-Firefox.zip` — Firefox Manifest V3 build for temporary local install.

The extension stores only the idle-time preference in browser extension
storage. It does not collect or transmit browsing history, keystrokes, mouse
activity, or page contents.
