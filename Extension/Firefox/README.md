# YARIS Screensaver for Firefox

This Firefox package has the same features and settings as the Chrome/Opera
build. It uses a Firefox-compatible Manifest V3 background script.

## Try it locally

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on**.
3. Select this folder's `manifest.json`.
4. Open the extension popup to set the idle time (1 to 1440 minutes).

Temporary add-ons are removed when Firefox closes. A persistent public
installation requires signing and distribution through Firefox Add-ons.
